# SurvivAlgo - Client

백준(Solvedac) 사용자들을 위한 알고리즘 문제 풀이 추적 및 경쟁 서비스의 프론트엔드

## 기술 스택

- React 19 + TypeScript + Vite
- TanStack Query, Zustand
- React Hook Form + Zod
- Tailwind CSS + DaisyUI

## 환경 변수 설정

`.env` 파일 생성:

```env
VITE_API_URL=http://localhost:8000
```

## 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```
